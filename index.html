Kopuz

A Flatpak repository for Kopuz, built for x86_64 and aarch64.

Install

Install the application directly:

flatpak install --user --or-update \
    https://kopuz-org.github.io/kopuz-flatpak/moe.kopuz.kopuz.flatpakref

Add the repository

Or add the remote and install from it:

flatpak remote-add --user --if-not-exists kopuz \
    https://kopuz-org.github.io/kopuz-flatpak/index.flatpakrepo
flatpak install --user kopuz moe.kopuz.kopuz

Run

flatpak run moe.kopuz.kopuz

Builds are signed with GPG and published from Kopuz-org/kopuz-flatpak.
